# AI 工具资源推荐与对比


## 一、AI 中转站推荐

官方API价格普遍偏高，尤其Claude系列。对个人程序员和学生开发者来说，中转站几乎是必需品。

### 1. ASYN API
- **主站**：https://asynapi.top
- **定位**：学校实验室内部自营中转站，出问题有保障，模型质量无掺水，价格相对较低，推荐使用。
- **特点**：自营，校内实验室自营，出问题可追溯；支持Claude、GPT、Gemini、Deepseek、Grok等主流模型。

### 2. 第三方其它中转站
- **当前情况**：目前可使用的中转平台较多，但是需要自己擦亮眼辨别，充值需采用少量多次的策略，防止中转站跑路造成太大的亏损。
- **价格**：目前主流计费方式是按量计费，一半价格约官方价格的 0.3x - 0.5x 倍率左右。

### 3. 共享账号
- **方式**：多人一起购买Claude/ChatGPT/Gemini账号，拼车使用同一账号。
- **优点**：便宜，直接使用官方账户，无需折腾API。
- **缺点**：有封号风险，多人共用，隐私性差。同时闲鱼平台对相关商品管控较严，Open AI 官方也在逐渐加大力度审查多人使用共享账号的情况。

### 官方 vs 中转站对比

| 渠道 | 价格 | 稳定性 | 适合人群 |
|------|------|--------|----------|
| 官方订阅 | 高 | 高 | 预算充足、重度依赖 |
| 中转API | 低 | 看服务商，优先选择 ASYN API，其次再选择其它第三方中转站 | 开发者、需API集成、需要短期使用 |
| 共享账号 | 中 | 低，有封号风险 | 适合自己与朋友拼车使用 |

> **风险提示**：中转站涉及账号共享和密钥管理，切勿在不可信平台存放敏感数据；API Key务必定期更换，避免泄露。

## 二、大语言模型对比

### 国外三大模型（御三家）

#### Claude（Anthropic）
- **强项**：代码理解、架构设计、大型项目、Agent式工作流。公认代码能力第一梯队。
- **弱项**：官方订阅价格高，API费用昂贵，封号较频繁。
- **推荐指数**：★★★★☆

#### ChatGPT（OpenAI）
- **强项**：综合能力均衡，Codex终端工具稳定，代码能力同属第一梯队，价格较低，性价比高。
- **弱项**：代码能力稍次于 Claude，但是它的价格弥补了这一点。
- **推荐指数**：★★★★★

#### Gemini（Google）
- **强项**：超长上下文、多模态能力、搜索整合优秀；前端代码能力优秀。
- **弱项**：历史上有过降智问题，但近期已恢复；API生态略逊于前两者。
- **推荐指数**：★★★★☆

### 国内实用模型

| 模型 | 出品方 | 强项 | 弱项 | 推荐场景 |
|------|--------|------|------|----------|
| DeepSeek | 幻方 | 性价比极高，V4 Flash 速度快，V4 Pro 模型能力在极限情况下可以勉强达到 GPT 水准 | 产品体验一般（非互联网公司） | 开发者API调用、自部署 |
| Qwen | 阿里 | 办公场景强，开源模型优秀，会议纪要/文档整理/邮件起草准确度高 | 生活化场景弱 | 办公、文书处理 |
| 豆包 | 字节 | 日活最高，语音/视频/生活场景最接地气 | 复杂开发能力一般，Agent模式弱 | 日常聊天、简单问答 |
| 元宝 | 腾讯 | 微信生态打通，接入DeepSeek后性价比突出，生活场景方便 | 开发能力一般 | 生活服务、轻办公 |

### 模型选择速查

- **写代码/大型项目** → GPT > Claude > DeepSeek
- **日常问答/搜索/写作** → Gemini > 豆包 > 千问
- **办公文档/会议纪要** → Kimi Work > 千问 > 元宝

## 三、AI Agent应用对比

### 1. AI原生/增强型IDE（VS Code系）

#### Cursor
- **地位**：目前最强AI编程IDE，行业标杆。
- **优势**：对Claude支持最佳，上下文理解、代码修改、Agent式编程体验顶尖；界面与VSCode几乎一致，迁移成本零；订阅价格相对良心。
- **劣势**：订阅制收费，免费版有限制。
- **适合**：重度开发者、专业项目、追求效率。

#### Trae（字节）
- **优势**：免费额度高，体验接近Cursor；中文界面友好；分国内版/国际版。
- **劣势**：生态和插件略逊于Cursor。
- **适合**：预算有限、学生、个人开发者。

#### Continue.dev（开源插件）
- **优势**：完全开源，高度可定制，支持任意模型（可接DeepSeek、本地模型等）。
- **劣势**：需要手动配置，开箱体验不如Cursor/Trae。
- **适合**：喜欢折腾、自建环境、隐私敏感者。

#### GitHub Copilot
- **优势**：VS Code深度集成，学生/教育账号免费；代码补全体验流畅。
- **劣势**：个人订阅涨价，智能度和速度不如前三者；建议质量一般。
- **适合**：学生（免费）、已有GitHub Pro用户。

#### OpenCode
- **优势**：完全开源免费，社区驱动，更新积极。
- **劣势**：功能完善度不及商业产品，需要一定技术能力。
- **适合**：不想花钱、想自部署、极客用户。

### 2. 终端/命令行工具

#### Claude Code
- **优势**：适合大型项目，代码理解和架构设计公认强；可与MCP/Skill/CCW体系深度集成。
- **劣势**：官方价格高；配置有一定门槛。
- **最佳用法**：通过中转API使用，或在Cursor中调用Claude模型替代。

#### OpenAI Codex
- **优势**：成熟稳定，界面简洁，开箱即用；适合服务器环境、快速原型。
- **劣势**：默认仅GPT系列，想用其他模型不便；大型项目上下文理解不如Claude Code。
- **最佳用法**：日常脚本、轻量开发。

### 3. 其他值得关注的工具

- **Deepseek Harness**：Deepseek的新开源Agent框架，万物皆插件，但是还属于初期阶段，建议观望，不建议作为主力Agent。
- **WorkBuddy**：国内综合体验好，打通腾讯生态，微信小程序/公众号开发支持到位。
- **Kimi Work**：长文本调研、Office文档处理扎实，适合非编程场景。
- **Zcode**：接近Codex体验，但大型项目吃力，适合小中型项目。
- **Catpaw（美团）**：需邀请码，暂未完全公开。
- **Qcoder（阿里）**：模型能力强，价格偏贵，适合预算充足且对质量要求极高的用户。

### 4. Agent协作体系简析（Rule/MCP/Skill/CCW）

当前AI工具明显向**Agent化**演进，理解以下概念，能更好的使用 AI 工具：

| 组件 | 约束级别 | 作用 | 示例 |
|------|----------|------|------|
| Rule | ★★ | 静态约束，定义角色和行为边界 | `.cursorrules`、`AGENTS.md` |
| MCP | ★★★ | 提供外部能力（文件、数据库等） | `filesystem-mcp`、`postgres-mcp` |
| Skill | ★★★★ | 锁定执行流程，强制步骤 | `Refactor Workflow` |
| CCW | ★★★★★ | 系统级编排，多Agent协同 | 状态持久化、强制任务规划 |

**核心思想**：把“概率性AI生成”变成“确定性工程交付”。通过Rule定底线、MCP给能力、Skill锁流程、CCW控全局。

## 四、按需推荐组合方案

作为学生，在预算有限的情况下，应该选择：
- **来源**：ASYN API 中转站或DeepSeek 官方API
- **应用**：编程优先使用Codex/Claude Code，学习问答优先使用Deepseek网页版或豆包网页版

## 五、结语

- **中转站**首选自营ASYN API，其次自己测试选择靠谱的中转站，采用少量多次的充值策略；
- **模型**日常问答使用网页版免费模型，开发用Claude/ChatGPT，性价比选DeepSeek；
- **Agent应用**优先选择Codex、Claude Code。
